## 开场（2 分钟）——先立论

各位好。今天不从「我们快了多少倍」讲起，而从动态场景下的工程目标讲起：

> **光计算最贵。要跟手，只能靠「复用」或「低成本替换」。**  
> **普通神经渲染能换光算法，是因为 Direct / Indirect 本来就可分；**  
> **RenderFormer 把几何与光照杂糅进全局 VI，直射进不了跟帧——两条路都堵死。**  
> **本仓库先做语义分离，再谈复用与替换。**

本仓库要做的第一件事，是 **语义分离**：

\[
L = L_{\mathrm{direct}} + L_{\mathrm{indirect}}
\]

让这两项在**合同上**可以分开调度、分开信任、分开学习。

请记住因果顺序（板书）：

```text
动态跟手需要：复用 或 低成本替换
    │
    ▼
普通神经渲染：换光算法（先有 DI 合同）✓
RenderFormer：token 杂糅 → VI 全局 → D 不能跟帧 → 两条路堵死
    │
    ▼
语义分离 CacheFormer：L = D + α·I（主线）
    │  允许
    ▼
低成本替换 D（每帧）· 复用/降频 I（合法对象）
    │  表现为
    ▼
效率与跟手性（结果，不是起点）
```

**三句话定调**：

1. **主线是语义分离**（否则复用与低成本替换双双无从落地）。  
2. **效率是分离的下游结果**（Hybrid → C1 → Cache / Layered）。  
3. **不重训大模型**——冻结核 RF，只改合同与小模块。

## 第一章：问题陈述——动态场景下为何必须语义分离（6–8 分钟）

> **本段是整场的问题定义**。后面 Hybrid / C1 / Layered 都是在回答：分离之后，「复用」与「低成本替换」如何各自落地。

### 1.0 目标：动态场景下的两类手段

渲染里，**光计算占算力最高**。动态场景（相机动、物体动、材质/光照变）要跟得上手，工程上只有两条路：

| 手段 | 含义 | 对本仓库 |
|------|------|----------|
| **复用** | 上一帧/上一状态的昂贵结果还能用 → 跳过整段重算 | VI Cache、隔帧 RF、I-buffer、Warp |
| **低成本运算替换** | 贵算法换成便宜近似，或只更新必须跟帧的分量 | Runtime Direct 每帧；跳过帧用 Warp/L2；α 降权 |

两条路都要求：**被复用或被替换的那一块，在合同上必须独立**。若直射与间接缠在同一张输出里，既不敢整图过期（复用失败），也无法只换掉「跟帧那一半」（替换失败）。

### 1.1 对照：普通神经渲染怎么提效

常见神经渲染 / 混合管线的思路是：**替换光的计算算法**——例如经典 Direct + 神经 Indirect（NRC 一脉）、屏幕空间间接、缓存辐照度场等。

关键在于它们往往先承认一条物理合同：

\[
L = L_{\mathrm{direct}} + L_{\mathrm{indirect}}
\]

于是可以：

- Direct 用光栅 / 阴影图 **每帧跟相机**（低成本替换「直射腿」）；  
- Indirect 用网络 / 缓存 **降频或复用**（复用「间接腿」）。

效率来自「腿可以分开调度」，不是来自「网络更大」。

### 1.2 困境：RenderFormer 把数据与语义杂糅进同一条 Transformer

官方 RenderFormer **不是**「只替换间接光算法」的支路，而是把 **三角面片整包** token 化后送入网络：

`	ext
顶点 / 三角几何 / 材质 / 发射（光照相关）
        ↓ 杂糅进同一套三角 token
   VI（场景全局光传输，与相机无关，最贵）
        ↓
   VD（射线 → 像素）
        ↓
   全图 HDR N   ← 直射与间接煮在一锅，无独立 I
`

因此出现三层绑死（口述放慢）：

1. **数据杂糅**：几何、材质、光照相关量进同一套 token，没有「只动相机 / 只动直射」的干净接口。  
2. **VI 只能全局更新**：场景指纹一变（物体位移、材质改），整场景 VI 往往要重跑；即便相机未动，也难做局部失效。同场景仅相机变时，CacheFormer 的 VI Cache 才能命中——**动态物体场景下 VI 复用空间极窄**。  
3. **Direct 无法进入跟帧合同**：输出是整锅 \(N\)，没有一等公民的 \(D\) / \(I\)。直射本该每帧经典算、硬阴影跟玩法，却被绑在整帧 Transformer 上。

**推论（必讲）**：在这种合同下，

- **复用无从落地**——复用 \(N\) = 直射一并过期（见 §1.4）；  
- **低成本替换无从落地**——没有独立的「直射腿」可换成 Runtime Direct，也没有独立的「间接腿」可换成 Warp / 小头 / 降频填充。

表面痛点是「慢、糊、跟不上」；根因是 **语义与数据绑死，不是单缺一个更快的 kernel**。

| 表面痛点 | 根因 |
|----------|------|
| 交互跟不上 | 全图 \(N\) 每帧绑定 VI+VD |
| 硬阴影糊 | 直射被整锅神经端带走，无法经典跟帧 |
| 想降频间接 / 复用 RF | **合同上不允许**——没有独立的 \(I\) |
| 想训「更好的间接」 | 监督仍是全 GI，不是 \(I^*\) |
| 动态场景想局部更新 | token/VI 全局耦合，难局部失效 |

若只抠算子加速、不拆合同，永远是「更快的一锅端」，不是「可工程化的 DI/II 分治」。

### 1.3 方案：语义分离的 CacheFormer

因而提出：**在冻结官方 RF 权重的前提下，做 Direct / Indirect 语义分离**（本仓库主线），再在分离合同上挂复用与低成本替换。

\[
L = D + \alpha \cdot I
\]

| 步骤 | 做什么 | 打开哪扇门 |
|------|--------|------------|
| **Hybrid（方案四）** | Runtime Direct + \(I=\mathrm{clamp}(N-D,0)\) + confidence \(\alpha\) | **合成合同**：\(D\) 可跟帧；\(I\) 可降权、可与 \(D\) 不同步 |
| **C1** | 监督 \(I^*=\mathrm{clamp}(L_{\mathrm{GT}}-D,0)\)；小头学间接 | **学习合同**：间接成一等公民，可走向专用支路 |
| **VI Cache / Layered L1–L3** | 同场景省 VI；隔帧填 \(I\)；跳过帧 Warp | **分离之后的结果**：复用与低成本填充 |

对应「两类手段」如何被允许：

`	ext
低成本替换：D ← Runtime Direct（每帧）
            跳过帧 I ← Warp / 可选 L2（毫秒级），而非整锅重跑 RF

复用：      刷新帧 I ← RF(±VI Cache)；隔帧沿用 / 重投影 I-buffer
            （复用对象是 I，不是整锅 N）
`

**金句**：

> 普通神经渲染靠「换光算法」提效；RF 先把几何与光照杂糅进全局 VI，直射进不了跟帧。  
> CacheFormer 先做**语义分离**，才让「复用」与「低成本替换」在动态场景下同时成立。

### 1.4 【必讲】为什么语义分离之后才能走「RF 复用」

> **口述金句**：RF 复用的是「可以过期的那一块」；一锅端的 \(N\) 里直射不能过期，所以没法安全复用。

**一锅端时，所谓复用 = 整锅过期**

RF 输出的是整图 \(N\)，里面 \(D\) 与 \(I\) 缠死。若某帧「跳过 RF、沿用上一帧结果」：

- 相机一动，**直射 / 硬阴影**本该立刻变，却还停在旧 \(N\) 里 → 跟手性崩。  
- 你也无法只说「间接先用旧的」——合同里根本没有独立的 \(I\)。

因此这时的「RF 复用」只能是：**整帧画面过期**，工程上不可接受。不是算力不够聪明，是**没有合法的复用对象**。

**分离之后，复用才有合法对象**

合同改成 \(L = D_{\text{每帧}} + \alpha\cdot I_{\text{可过期}}\) 之后：

| 分量 | 更新频率 | 为何可以这样 |
|------|----------|--------------|
| \(D\) | 每帧经典算 | 跟相机/阴影，便宜、必须准 |
| \(I\) | 隔帧 RF / Cache / Warp | 变化慢、贵，允许陈旧，再靠 \(\alpha\) 降权 |

此时「少跑 RF」才说得通：

`	ext
复用的不是整锅 N，
而是间接相关量（I 或写入缓冲的间接填充）。
Direct 每帧新炒；Indirect 允许隔夜。
`

**务必强调的因果**（可放慢、可板书）：

1. \(D\) 与 \(I\) 的**时效与算力不对称**（根因）。  
2. 合同上拆开（语义分离）。  
3. 才允许对 \(I\) 降频 / 缓存 / warp —— 看起来像「RF 复用」，实质是 **间接填充复用**。

> 不是「先想加速，再拆成 DI」。  
> 是「先承认不能整锅过期 → 拆开 → 才敢复用贵的那条腿」。

### 1.5 我们不做什么

- 不从零训 2～4 亿参数大模型  
- 不做运行时 PT / NRC 在线训  
- 不把「加速比」写成唯一贡献——**贡献首先是合同**  
- 不声称「没拆语义也能安全整帧复用 RF」——那是整锅过期，不是本项目的复用

## 第二章：语义分离怎么落地（主线，12 分钟）

### 2.1 第一步：合成合同（Hybrid / 方案四）

对标 NRC「经典管 Direct、神经管 Indirect」：

```text
              ┌─ Runtime Direct ──► D      （每帧、跟相机）
场景 ─────────┤
              └─ RF → N ──► I = clamp(N−D, 0)
                              L = D + α · I
```

| 项 | 含义 |
|----|------|
| \(D\) | 0-bounce 直射、硬阴影、纹理 |
| \(I\) | 间接分量（先从 \(N\) 分解） |
| \(\alpha\) | 间接不可信时降权（violation / confidence） |

**关键澄清**：这一步已经是语义分离——\(I\) 可以降权、可以与 \(D\) 不同步刷新。  
但若仍**每帧**跑满 RF，大厨工时没省；分离只是打开了「以后可以降频」的门。

### 2.2 第二步：学习合同（C1）——间接变成可学量

Hybrid 的 \(I=\mathrm{clamp}(N-D,0)\) 仍是**事后分解**。C1 要把监督钉在间接上：

\[
I^{*} = \mathrm{clamp}(L_{\mathrm{GT}} - D,\ 0)
\]

\[
I_{\mathrm{pred}} = \mathrm{ReLU}\big(\mathrm{ReLU}(N-D)+\Delta\big)
\quad\text{（小头学 }\Delta\text{）}
\]

\[
L = D + \alpha\cdot I_{\mathrm{pred}}
\]

| | Hybrid 分解 | C1 |
|--|-------------|-----|
| 训练目标 | 无（用官方全 GI） | **最小化 ‖I_pred − I*‖** |
| 间接身份 | 派生量 | **一等公民** |
| 长期 | 离不开全量 \(N\) | 可走向特征头 / 异步填 \(I\) 缓冲 |

**做菜类比（可讲）**：

- RF：整锅端  
- Hybrid：整锅 + 一碟物理直射拼盘  
- **C1**：直射每帧炒；学徒专学「差多少勾芡」  

### 2.3 C1 阶段实际做了什么（工作清单）

| 里程碑 | 交付 | 状态 |
|--------|------|------|
| M0 | 合同与文档 | 完成 |
| M1 | GT/Direct 对齐，导出 \(I^*\) / gt_cache | 完成 |
| M2 | C1-a 训练 + 推理接 α；eval/compare | 完成 |
| M3 | 在「\(I\) 可缓冲」之上做隔帧/重投影质量锁定 | 完成（演进为 Layered） |

代码入口（口述点名即可）：

- 头：`renderformer/c1/residual_head.py`  
- 数据/训练：`tools/c1_prepare_dataset.py`、`c1_train.py`、`c1_eval.py`  
- 推理：`tools/c1_infer.py`、`c1_compare_modes.py`  

### 2.4 分离之后「允许」什么——因果链（回扣 1.3）

语义一经分开，下列技术**才有合法插入点**（尤其是 RF / VI 复用）：

| 技术 | 为何需要分离在先 |
|------|------------------|
| Direct 每帧跟相机 | \(D\) 不再绑死在整锅 \(N\) 上 |
| **RF / VI 复用（隔帧填 \(I\)）** | **复用对象是 \(I\)，不是整锅 \(N\)**；否则 = 直射一起过期 |
| \(I\) 隔帧 / 过期 | 间接允许 stale |
| 屏幕空间 warp(\(I\)) | 有独立缓冲可重投影 |
| VI Cache 只服务刷新帧 | 刷新的是「填 \(I\)」，不是整锅必出 |
| α / Direct-only 降级 | 只关间接旋钮 |
| C1 小头 | 监督目标是 \(I^*\)，不是全图 |
| 引擎异步 \(I_{\mathrm{buffer}}\) | 呈现永远 `D_now + α·I_buf` |

**金句（可连念）**：  
> 效率不是我们「另外做的一条加速线」；是语义分离之后，把 Indirect 当成缓冲来填时，自然长出来的能力。  
> **没有分离，就没有「只复用间接」——只能复用整图；所以分离是 RF 复用的前提，不是加速的事后包装。**

## 第三章：分离之后的管线形态（结果篇，8 分钟）

### 3.1 每帧合同（产品思维）

```text
每帧（跟玩法）：
  D_now（光栅） + α · I_buffer（可过期）

何时填 I_buffer（可降频）：
  跑 RF / C1 头 / warp 上一帧 I ……
```

对标 CacheFormer 色差时，用 `quality_anchor=rf`：证明「调度不伤 RF 外观」；  
产品形态用 hybrid：证明「分离合同真的跟手」。

### 3.2 Layered L1–L3：在 \(I\) 缓冲上长出来的调度

```text
L3：要不要刷新「神经腿」填缓冲？
  是 → VI(±Cache) → VD → 写入 fused / I
  否 → Warp(旧缓冲) → 可选 L2（含 C1 mix）
```

| 层 | 在语义合同里的角色 |
|----|-------------------|
| L3 | 决定何时**更新**间接相关量 |
| L1 | 间接缓冲的**跟视图**（时间复用） |
| L2 | 间接的**廉价修正**（门控 / 头） |

数字（结果，不是立论）：相对 CF 约 1.1–1.8×，相对纯 RF 约 3×；闸门 absL1\<0.08。  
跳过帧误差来自 warp，刷新帧与 RF 同图——说明**分离后的时间复用**在工作，而不是换了一套 GI。

### 3.3 职责边界（防抬杠）

| 模块 | 在语义故事里 | 不负责 |
|------|--------------|--------|
| Direct | 直射身份 | 决定是否刷新神经腿 |
| α | 信多少间接 | 决定是否刷新 |
| C1 | 间接学得好不好 | 单独「加速」 |
| L3/Warp | 分离之后的填充与复用 | 重新定义 GI 物理 |

## 第四章：实验怎么支撑这条叙事（5 分钟）

讲实验时也按因果说：

1. **先证明合同**：Hybrid/C1 能合成 \(D+\alpha I\)，Direct/Indirect 可分开展示（compare_modes）。  
2. **再证明分离带来调度空间**：Layered 少跑 RF，刷新帧 absL1=0，skip 帧才有误差。  
3. **指标**：speedup 是**结果指标**；absL1/PSNR 约束「复用间接时别伤太多」。

```bash
# 语义 / 头
python tools/c1_infer.py --h5_file tmp/cbox/cbox.h5 --checkpoint checkpoints/c1/best.pt --confidence

# 分离后的调度结果
python tools/benchmark_layered_vs_cf.py --h5_file tmp/cbox/cbox.h5 \
  --pipelines renderformer,cacheformer,layered
```

## 第五章：收束（3 分钟）

### 带走的因果

```text
动态跟手需要：复用 或 低成本替换
  → 普通神经渲染：先有 DI 合同，才能换光算法
  → RF：token 杂糅 → VI 全局更新 → D 不能跟帧 → 两条路堵死
  → 语义分离（Hybrid + C1）：L = D + α·I
  → 低成本替换 D；复用/降频 I（不是整锅 N）
  → 效率与跟手性（结果）
```

### 结束语

> 动态场景要跟手，靠的是复用与低成本替换；二者都以 Direct / Indirect 可分为前提。  
> RenderFormer 把几何与光照杂糅进全局 VI，直射进不了跟帧，两条路都无从落地。  
> CacheFormer 的核心贡献，是在冻结官方权重下先写清 **\(L=D+\alpha I\)** 的合同：Direct 每帧经典跟玩法，Indirect 才成为可缓存、可降频、可学习的对象。速度数字验证的是这条路走得通，而不是项目的第一目标。

## 附录 B：板书

**板书 1 — 问题主链（与用户提纲同构）**

```text
动态场景跟手 ──需要──► 复用  或  低成本替换
普通神经渲染 ──靠──► 换光算法（先有 DI 合同）
RenderFormer ──因──► token 杂糅 → VI 全局更新 → D 不能跟帧
              ──故──► 复用 / 替换 双双无从落地
CacheFormer  ──先──► 语义分离 L=D+αI
              ──才──► 两类手段同时成立 → 效率（结果）
```

**板书 2 — 合同**

```text
L = D + α · I
D：经典，跟玩法（低成本替换）
I：神经先验 / C1，可缓冲（复用对象）
```

**板书 3 — 为何分离才能 RF 复用（必写）**


## 附录 D：连贯口述稿（由用户提纲扩写，可直接念）

在动态场景下，要让全局光照跟得上手，工程上无非两类手段：**复用**上一帧或上一状态的昂贵结果，或用**低成本运算替换**贵算法——只更新必须跟帧的那一部分。

渲染中，光计算占用的算力最高。普通神经渲染往往通过**替换光的计算算法**来提效：直射走经典管线、间接走网络或缓存。这之所以可行，是因为它们通常先承认 Direct / Indirect 可以分开调度。

RenderFormer 则不同：它把整个三角面片送入 Transformer，顶点、几何、材质与光照相关量**杂糅**在同一套 token 里，经 VI 做场景全局光传输再经 VD 出像素。结果是：VI 往往只能**全局更新**；输出又是直射与间接缠在一起的整锅 \(N\)，**Direct 进不了跟帧合同**。于是，无论是整图复用，还是只替换直射腿、降频间接腿，在合同上都无从实现——复用会把直射一并过期，替换则找不到独立对象。

因而本仓库提出**语义分离的 CacheFormer**：在冻结官方 RF 权重的前提下，用 Hybrid 建立 \(L=D+\alpha\cdot I\) 的合成合同，用 C1 让间接成为可学习的一等公民，再在此合同上引入 VI Cache、隔帧填充与 Warp 等。分离之后，**低成本替换**体现为每帧 Runtime Direct 与跳过帧的廉价间接近似；**复用**体现为对间接缓冲（而非整锅 \(N\)）的 Cache / 降频 / 重投影。效率与跟手性，是这条语义主线允许技术进入之后的结果，而不是第一性原理。
